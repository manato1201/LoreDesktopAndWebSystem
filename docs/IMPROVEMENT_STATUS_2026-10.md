## 未決(仕様の確認が必要 — 変更していない)

Z32 の点検で見つかったが、**意図した仕様かもしれない**ため、挙動を変えずに表(TECHNICAL_REFERENCE.md §4.3)へ記録した。

1. リポジトリ設定の更新(`PATCH`)は一般メンバーも実行でき、公開範囲(private→public)も変えられる。
2. ツリー・コミット一覧・コミット詳細は、パスACLで読めないファイルの名前も返す。
3. 監査ログと権限の一覧は、全メンバーが読める。
4. 「現在のブランチ」がリポジトリごとにサーバーに1つなので、誰かが checkout すると全員の `GET /tree` が変わる。

### 点検で見つかった、まだ直していないもの

1. `change_password`・`accept_invite`・`reset_password` も、ロックを握ったままハッシュを計算している(競合の検討が要る)。
2. `login` は存在しないメールで検証をしないので、応答時間の差でメールの有無が分かる余地がある。
3. ファイルの種類の表が、API と Web に二重にあり、すでにずれている(影響はアイコンのみ)。

詳細と直し方は [学習資料 13 のレシピと課題一覧](learning/13-extend-recipes.md) にある。
